# Contracts, FR-006, and Normalization Checklist: PhotoCraft MCP Verified Local Smoke

**Purpose**: Unit-test the quality of 007 requirements for public contract preservation, reuse of the 006 MCP adapter, FR-005/FR-006 non-regression, and structured failure/normalization metadata — so gaps, ambiguities, and inconsistencies are found before implementation or verification work begins. This checklist evaluates **requirements writing**, not implementation behavior or test execution results.  
**Created**: 2026-11-05  
**Feature**: `specs/007-photocraft-mcp-smoke/spec.md` (Draft, clarified C1–C4; scoped go Option A — stateless verified smoke) · `plan.md` · `data-model.md` · `contracts/photocraft-mcp-smoke-contract.md` · `quickstart.md`  
**Review Ownership**: Feature author / reviewer owns requirement-quality disposition; checklist is a reviewer-owned artifact. Functional conformance is proven separately by mock-first/default gates and opted-in evidence (not by checking items here).  
**Marker Semantics**: `[ ]` = requirement quality not yet reviewed for this item; `[x]` = reviewed and requirement text is sufficiently complete/clear/consistent/measurable for this concern (or an explicit documented gap/decision exists). Markers do **not** attest implementation, passing tests, or real PhotoCraft execution.
