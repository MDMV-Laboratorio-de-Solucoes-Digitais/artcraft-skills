# Policy Redaction

## Purpose
Composable redaction middleware for removing sensitive information from content.

## When to Use
Apply to any text-producing skill for content safety and compliance.

## Features
- Configurable redaction rules
- PII detection and removal
- Pluggable as middleware
- Composable with any skill

## Generalizable
No project-specific rules - fully configurable.

## Usage
Apply as pre/post processing middleware in skill composition.
