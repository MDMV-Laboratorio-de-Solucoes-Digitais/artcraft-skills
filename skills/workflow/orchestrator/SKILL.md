# Workflow Orchestrator

## Purpose
Orchestrate complex workflows by composing multiple skills in sequence or parallel with state management.

## When to Use
When building end-to-end creative pipelines across multiple skills and asset types.

## Features
- DAG execution
- Parallel and sequential composition
- State management
- Error handling and retries
- Progress tracking

## Usage
Compose atomic skills into workflows for cross-product integration.

## Limitations
Requires skills to follow standard interfaces.
