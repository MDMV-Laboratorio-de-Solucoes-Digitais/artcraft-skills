# Generalizable Workflows

This document describes generalizable workflow patterns derived from common needs.

## Workflows
- **Structured Packager**: Package assets and data into reproducible bundles
- **Policy Redaction**: Apply redaction policies to content
- **DAG Orchestrator**: Execute complex workflows as DAGs
- **Evidence Audit**: Track and verify artifacts with content addressing

## Design Principles
All workflows are designed to be general-purpose with no project-specific branding or assumptions.
